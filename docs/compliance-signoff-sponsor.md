## 三、必须修改项（MUST-FIX，不完成不得作为付费上线依据）

### MUST-FIX #1 — 明确"首版不输出健康段"
- **位置**：§3.3 医疗/健康 + §二/L3 触发逻辑
- **问题**：§3.3 目前写"允许：仅导向'请咨询持证医师'"，暗示报告可含健康段。但我在 `sponsor.md` Q4 明确写：**"健康——风险最高，首版不输出健康段"**，且"禁止任何症状/疾病/身体部位推断"。当前措辞与我自己写下的底线不一致，会在模板审核时留下歧义，构成潜在风险敞口。
- **修改建议**：在 §3.3 顶部新增硬约束：
  > **阶段 0（验证期）报告模板不得包含任何健康/医疗段，无论是否仅作导向。** 仅当用户输入或 AI 输出流中识别到自伤/危机信号时，按 §3.9 转 L3 后缀；除 L3 外，AI 不得主动生成任何健康/医疗相关内容。后续若开放健康段，只允许"规律作息/定期体检，以专业医疗意见为准"类无信息量表述，且须先过律师意见。
- 同步将 §3.3 末句"允许：仅导向'请咨询持证医师'"改为"**阶段 0 禁止；仅 L3 危机路径可导向**"。

### MUST-FIX #2 — 显式声明"付费不改变免责底线"
- **位置**：§一 平台定位声明（或新增小节）
- **问题**：`sponsor.md` Q4 底线"**付了钱也不卖'确定性'**"。v1 未明确付费报告同样受本清单约束，可能被理解为"免费才免责、付费可放宽"。
- **修改建议**：在 §一 增加一句：
  > **本清单对所有内容生效，付费深度报告不例外——付费只改变内容深度，不改变"不卖确定性"的底线。**

## 四、回答 v1 §六 的四个 sign-off 问题

**Q1 · L2/L3 是否需法务润色？**
需。运营 C3 要求阶段 1 前取得互联网/文娱方向**执业律师书面意见**。当前 L2/L3 作为**阶段 0 小额验证的临时版本可接受**（赞助人 Q4 已确认"阶段 0 小额验证可在律师意见到位前进行，但话术清单必须先落地"）。**条件**：文档须打标"待律师复核"，并在 I3（变现闭环）启动前设任务跟踪律师意见到位；阶段 1 规模化前未完成复核，则不得扩大付费投放。

**Q2 · 危机热线占位 12356 是否可接受？**
**以运营备案为准，占位暂可接受，但上线前必须确认。** 说明：全国心理援助热线 12356 为官方号码（2023-10 起启用），作占位合理；但须由运营核实①该号在运营所在地可接通且为当前有效号；②是否有属地更优的本地热线。v1 已注明"以运营实际备案热线为准"，此项满足"占位+待确认"口径，**不阻塞**，但 I3 收款前须替换/确认完毕。

**Q3 · 是否需补充行业条目（移民/考公等）？**
考公/上岸已隐含于 §3.7 职业/学业（趋势性参考），不需单列。**移民/签证建议补充**（见 SHOULD #3）：属法律/跨境合规高敏话题，应在 §3.4 或新增 §3.10 明确"不提供移民/签证可行性、成功率、时点断言，导向持牌移民/法律机构"。

**Q4 · 是否接受"输出侧软改写 + 输入侧硬拦截"为落地口径？**
**接受，且确认不可反转。** 此口径即 §4.3 架构裁决终案，优先于我早期赞助人评审中"命中即拦截"的过严表述——后者会误杀"我明年适合换工作吗"等正常命理问答，使主功能变拒答机器。本 sign-off 以最终架构裁决为准。唯一补充要求：输出侧软改写须配合 `ai_audit` 高风险标记 + **人工复盘**，不能"仅软改写不审"（见 SHOULD #4 与 §五 风险点）。

## 五、建议修改项（SHOULD-FIX，不阻塞 I1）

### SHOULD #1 — §5 候选 grep 词库误含产品自有词
- 现状：`紫微|斗数|六壬|奇门|塔罗|改运|化解|破灾|转运|guaranteed|100%`
- 问题：**紫微/斗数 是产品本体（辰箓即紫微斗数工具）**，放入违规 grep 词库会在未来 CI 门禁落地时误杀全部正当内容。六壬/奇门/塔罗 属 Charter §九 本阶段不做的新系统，亦非"违规话术"。
- 建议：违规词库只保留真正越界词——`改运|化解|破灾|转运|改命|开光|符咒|guaranteed|100%|绝对会`。产品/系统名不进违规库。（本阶段不落地，先更正候选定义，避免埋雷。）

### SHOULD #2 — 投资/情感允许项口径精修
- §3.5 允许项改为："仅允许性格/风险偏好层面的泛化表述，禁止任何标的/时点/金额暗示"。
- §3.6 允许项补："并明示'最终决定权在你'"。

### SHOULD #3 — 补充移民/签证条目（呼应 Q3）
- 新增 §3.10 或并入 §3.4：不提供移民/签证可行性、成功率、时点断言，导向持牌机构。

### SHOULD #4 — 厘清"自伤/危机"双路径 + 软改写须配人工复盘
- 明确：输入含自伤指令 → 输入侧硬拦截拒答；输出流识别危机信号 → 转 L3 软改写。两路径在文档中分列。

## 六、风险提示：开放付费后最易被监管/用户举报的话术风险点

1. **健康段是头号雷区（最高）**。一旦付费深度报告出现任何健康/身体推断，无论是否"仅导向"，都可能触发"利用封建迷信"或医疗误导举报。MUST-FIX #1 把它从模板里彻底拿掉是首要防线；L3 仅作危机兜底。
2. **"趋势性表述"被读成"断言"**。即使用"偏有利/相对平稳"，付费用户截图举报时易放大解读为预测承诺。建议 `ai_audit` 对所有付费输出做更高阈值标记，人工抽检比例高于免费。
3. **退款说明真实性（C5/C8 联动）**。若定价页退款说明不真实可执行，叠加"付费算命"属性，极易构成虚假宣传举报。话术清单须与 P0-8 定价页退款条款互审。
4. **危机热线失效/错误（L3）**。12356 若在当地不可接通或已变更，用户危机时得不到帮助 → 道德与监管双重风险。Q2 上线前确认是硬前提。
5. **营销内容（小红书/分享卡）过度承诺**。广告法对迷信宣传有限制，对外引流文案若用"准""灵""改运"等词，风险高于产品内文。建议内容口径单独加一条"对外文案禁止绝对化/改运词"。
6. **个人码经营性收款（已识别，止损线 D5）**。累计 ¥1,000 或第 20 笔须切换商户码，否则微信/支付宝限冻结 + 税务风险。属运营合规，非本清单范围，但同为零事故一票否决项，列此互提醒。
