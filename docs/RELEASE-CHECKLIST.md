## 1. 文案 ⇄ 实现一致性 · 逐项核对（核心，防复发）

原则：**任何面向用户的「能力宣称」都必须有对应实现；无实现的术数品类不得作为功能承诺出现。**
产品当前**仅支持八字排盘**（无紫微斗数 / 六爻 / 塔罗 / 奇门）。

| 2 | 其他未实现术数品类（六壬/奇门/塔罗/紫微星名） | grep `斗数\|六壬\|奇门\|塔罗` | 装饰性引用不得与「AI 答疑 / 功能」绑定 | ✅ 已清零 |

## 3. 埋点骨架核对（I0 · Task 3）

复用现有单端点 `/api/track`，新增以下 action（已加入 `server.js` `TRACK_ACTIONS` 白名单）：

| action | 触发语义 | 当前接线位置 | 状态 |
|--------|----------|--------------|------|
| `pricing_viewed` | 定价/套餐页曝光 | 待定价页上线后接线 | ✅ 已白名单，可记录/查询 |
| `paywall_hit` | 触发付费墙（需登录/付费） | 待付费墙上线后接线 | ✅ 已白名单，可记录/查询 |
| `redeem_success` | 兑换码兑换成功 | 待兑换功能上线后接线 | ✅ 已白名单，可记录/查询 |
| `login_wall_view` | 登录墙（登录页）曝光 | `public/login.js` 游客加载时上报 | ✅ 已接线 + 已白名单 |
| `home_anon_view` | 游客浏览首页 | `public/index.js` 游客加载时上报 | ✅ 已接线 + 已白名单 |
| `share_generated` | 生成分享链接 | 待分享功能上线后接线 | ✅ 已白名单，可记录/查询 |
| `source_self_report` | 用户自报来源 | 待来源自报上线后接线 | ✅ 已白名单，可记录/查询 |

校验方式（测试环境，需 Postgres）：
```bash
# 记录
curl -s -X POST http://localhost:8787/api/track \
  -H 'Content-Type: application/json' \
  -d '{"action":"home_anon_view","payload":{}}'   # 期望 {"ok":true}
# 查询
psql "$DATABASE_URL" -c "SELECT action, count(*) FROM events WHERE action='home_anon_view' GROUP BY action;"
```
