# 深度报告话术禁止清单（COMPLIANCE-WORDING）

- 版本：**v1.1**
- 依据：Charter 决议 C2、F6、§九；架构裁决 §4.3
- 状态：**已批准（APPROVED，MUST-FIX #1/#2 已落实，SHOULD 已消化）**
- 用途：① 后端输出侧软改写（DISCLAIMER_L2 / L3）的内容基准；② 前端展示边界；③ 人工审核 / `ai_audit` 复盘基准；④ 未来 CI grep 门禁候选词库（本阶段不落地，见 Charter §九）
- 跟踪：**待律师复核**（L2/L3 为阶段 0 临时版，I3 收款前须取执业律师书面意见并确认 12356 备案）

> **架构裁决（不可反转）**：输入侧可硬拦截，输出侧只能**软改写**（追加免责后缀），**禁止**对 AI 输出做"预测性断言"的自动硬拦截——否则会把"我明年适合换工作吗"这类正常命理问答误杀成拒答机器。

## 一、平台定位声明（全局前置）

- 定位：传统命理文化的**娱乐性解读**工具，内容由 AI 生成，**不构成任何专业建议**。
- **禁止**自我定位为：医疗机构、律所、金融机构、心理咨询机构、或任何"改运 / 化解"服务机构。
- **本清单对所有内容生效，付费深度报告不例外——付费只改变内容深度，不改变"不卖确定性"的底线。**

## 二、输出侧系统免责后缀（代码实现用，SSE 流末追加）

- **DISCLAIMER_L2（普通命理问答）**：
  > 以上内容为传统命理文化的娱乐性解读，由 AI 生成，不构成医疗、法律、投资或任何专业建议。涉及健康、法律、财务等重大决策，请咨询对应持证专业人士。

前端须以**视觉区分**渲染（分隔线 + 灰色小字 + 图标），不得混为 AI 正文。

## 三、话术禁止清单（硬禁区）

### 3.1 绝对化预测
- 禁止：「一定 / 肯定 / 必然 / 100% / guaranteed / 绝对会」等断言性预测。
- 禁止宣称预测"绝对准确""不会出错""已验证有效"。
- 允许：趋势性、或然性表述（"偏有利 / 需注意 / 相对平稳"）。

### 3.2 改运 / 化解类（红线，与 P1-5 同属绝对禁区）
- 禁止任何"改运 / 转运 / 破灾 / 化煞 / 改命 / 开光 / 符咒 / 风水布局改命"的功效承诺或暗示。
- 禁止售卖或引导购买任何"化解 / 转运"物品或服务。

### 3.3 医疗 / 健康

**阶段 0（验证期）报告模板不得包含任何健康/医疗段，无论是否仅作导向。** 仅当用户输入或 AI 输出流中识别到自伤/危机信号时，按 §3.9 转 L3 后缀；除 L3 外，AI 不得主动生成任何健康/医疗相关内容。后续若开放健康段，只允许"规律作息/定期体检，以专业医疗意见为准"类无信息量表述，且须先过律师意见。

- 禁止诊断疾病、开具方剂 / 食疗方、断言寿命 / 死期、判断受孕性别。
- 禁止"此卦显示你身体有恙"类伪诊断。
- 阶段 0 禁止；仅 L3 危机路径可导向。

### 3.4 法律
- 禁止给出具体法律意见、诉讼结果预测、合同条款效力判定。
- 允许：导向"请咨询执业律师"。

### 3.5 投资 / 财务
- 禁止推荐具体标的、断言涨跌、承诺收益、暗示"稳赚"。
- 禁止"此命格适合炒 XX"类引导。
- 允许：仅允许性格 / 风险偏好层面的泛化表述，禁止任何标的 / 时点 / 金额暗示。

### 3.6 情感 / 关系
- 禁止教唆控制 / 报复他人、断言"必然复合 / 必然分手 / 对方必出轨"。
- 允许：关系趋势性参考，强调尊重与沟通，并明示"最终决定权在你"。

### 3.7 职业 / 学业
- 禁止断言"必然升职 / 必然被裁 / 必然上岸"。
- 允许：趋势性、准备度参考。

### 3.8 身份与资质误导
- 禁止声称"大师 / 神算 / 祖传秘方 / 官方认证"。
- 禁止伪造任何资质背书。

### 3.9 危机干预（输出侧软改写路径）
- 涉及输出流中识别到的自伤 / 轻生 / 危机信号：不展开命理分析，直接给求助指引（触发 L3 软改写后缀）。

**双路径区分（不可混）**：
- **输入含自伤 / 违法指令** → 属 §四 输入侧硬拦截（`isBlocked`），返回固定合规拒答，内容不进入 AI；
- **AI 输出流中识别到危机信号** → 属本条输出侧路径，转 L3 软改写，不展开命理分析。
- 两路径触发时机不同，互不可替代：输入侧挡指令，输出侧救信号。

### 3.10 移民 / 签证
- 不提供移民 / 签证可行性、成功率、时点断言，导向持牌移民 / 法律机构。

## 四、输入侧硬拦截（沿用现有 `isBlocked`，不进入 AI）

触发即返回固定合规拒答：
- 具体自伤 / 违法 / 伤害他人指令
- 明确要求伪造资质 / 文件的指令
- 其他违反内容安全策略的请求

---

## 五、审核与复盘

- 所有 AI 输出经 `ai_audit` 标记；高风险样本人工复盘。
- 本清单为 `docs/RELEASE-CHECKLIST.md` 引用项；每次 PR 人工核对是否新增违规话术。
- 候选 CI grep 词库（本阶段不落地，见 Charter §九），仅保留真正越界词（产品/系统名不进违规库，避免误杀正当内容）：
  `改运|化解|破灾|转运|改命|开光|符咒|guaranteed|100%|绝对会`
- 输出侧软改写不得"仅软改写不审"，`ai_audit` 高风险样本必须人工复盘，作为 §4.3"禁止自动硬拦截"的对价控制。
