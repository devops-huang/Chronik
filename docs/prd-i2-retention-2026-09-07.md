- **原始需求复述**：Edward 拍板启动 I2 留存。在低频次命理娱乐产品上，通过节气/流年/命宫提醒、运势节点通知、分享卡召回、结缘堂权益递进、生日/周年彩蛋、内容订阅等杠杆提升回访；留存靠"节律/事件驱动"而非"每日打卡"；对齐北极星（首笔真实付费 G2）；不写代码，仅产出 PRD。

## 1. 产品目标

1. **节律驱动而非打卡**：八字用户天然 30–365 天间隔回访，强提醒/每日打卡与产品节律相悖且易被屏蔽。所有留存机制一律事件/节律触发（节气、流年、命宫变动、生日、到期）。
2. **对齐北极星（首笔付费 G2）**：I2 不做付费本身（属 I3），但建立"回访 → 更多排盘/AI → 付费意愿"漏斗前段；**回访习惯须在 G2 之前养成**。
3. **目标数字（建议，待拍板）**：沿用 RELEASE-PLAN §八 —— **Month-1 回访率 ≥15%**（原 30 日留存 25% 已因与低频节律不匹配被取消）、单次深度率 ≥30%、合规事故 0。

---

## 2. 用户故事

1. **新用户激活**：作为刚排盘的新用户，我希望在我生日/次年流年临近时收到一条温和的命理彩蛋或流年提醒，以便我愿意回来看一眼，而非一次性流失。
2. **回访节奏**：作为年度复访者（P2），我希望每个节气/流年转换时收到命宫/运势节点提示，以便我按自然节律回访，而非被每日推送打扰。
3. **结缘堂粘性**：作为付费用户（结缘堂），我希望到期前被告知并便捷续费（缘券/兑换码），以便我连续持有权益不被中断。
4. **召回流失**：作为注册后沉默的用户，我希望通过站内信/邮件收到一条带"我的命盘"回链的召回落地页（可一键分享），以便我低成本回到产品。
5. **内容留存**：作为轻度用户，我希望主动打开"周运/每周一卦"轻量内容，以便我在无排盘需求时也有理由偶尔回访（**拉取式，非推送**）。

## 4. UI 设计稿（关键留存界面 · 线框）

### 4.1 提醒设置页 `/settings/notifications`
```
[ 辰箓 · 提醒设置 ]
  命理节律提醒
    ○ 节气转换提醒       [开/关]   （约每 15 天，温和）
    ○ 年度流年/命宫变动   [开/关]   （每年 1–2 次）
    ○ 本命年/冲太岁临近   [开/关]   （多年一次，强提醒）
    ○ 生日彩蛋           [开/关]
  触达方式
    ☑ 站内信（默认）
    ☐ 邮件（需绑定邮箱）
  [ 保存 ]
  注：所有提醒均为节律/事件驱动，无每日推送。
```

### 4.2 召回落地页 `/r?ref=...`
```
[ 辰箓 · 欢迎回来 ]
  你的命盘仍在：<姓名/备注> 八字四柱摘要（脱敏）
  [ 查看我的流年/命宫变化 ]   [ 继续 AI 答疑 ]
  ── 或分享给朋友 ──
  [ 生成分享卡（文案卡）]
  文化研究与娱乐参考，不构成医疗/法律/投资建议。
```

### 4.3 权益中心 / 结缘堂 `/member`
```
[ 结缘堂 · 我的权益 ]
  状态：结缘堂会员（缘券余额：N）
  有效期至：YYYY-MM-DD  [ 续费 ¥99/年 ]
  ⚠ 将于 7 天后到期，续费可连续持有权益
  权益：每日 AI 30 轮 / 深度解读 / 专属节气提醒
```
